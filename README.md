# API Connect - MVP

Uma API RESTful minimalista e ágil desenvolvida para validar operações essenciais de gerenciamento de usuários. 

## 🚀 Tecnologias Utilizadas
- **Node.js**: Ambiente de execução JavaScript.
- **Express**: Microframework web para roteamento.
- **Crypto (Nativo)**: Geração de UUID v4.
